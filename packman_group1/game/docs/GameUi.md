# Реализация класса GameUi

## Параметры

```font_size``` - **Размер текста (Тип int).**

```font_color``` - **Цвет текста (pyray.ЦВЕТ).**

### Конструктор

**Конструктор просто принимает ранее перечисленные параметры**

---

### Метод draw_text

**Отрисовывает текст на заданных координатах, принимает на вход текст (Тип str) и координаты по x и y (Тип list[int]).**

---

### Метод update_score

**Отрисовывает колличество очков с помощью метода draw_text, принимает на вход колличество очков и координаты по x и y (Тип list[int])**

---

### Метод update_lives

**Отрисовывает колличество жизней с помощью метода draw_text, принимает на вход колличество жизней и координаты по x и y (Тип list[int])**
