# Дарова

Создаёшь переменную класса Points

типа a = Points()

add - добавить точку, x, y, тип(small или big)

remove - Удалить точку, в массиве они сортируются по времени создания

draw - отрисовать все точки, использовать надо когда в пайрее начинаешь отрисовку

getAll - получить массив со всеми точками
