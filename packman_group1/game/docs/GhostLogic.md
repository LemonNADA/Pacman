# Реализация класса GhostLogic

## Параметры

```x``` - **координата по x на которой должен заспавниться призрак (Тип int).**

```y``` - **координата по y на которой должен заспавниться призрак (Тип int).**

```size``` - **размер призрака в пикселях (Тип int).**  

```speed``` - **диапазон скорости призрака (Тип list[float] с двумя параметрами: минимальное значение диапазона и максимальное значениие диапазона)**

```texture``` - **текстура призрака (Ghost.png)**

```color``` - **цвет призрака (colors.ЦВЕТ)**

```walls``` - **стены карты (list[pyray.Rectangle()])**



### Конструктор

**Конструктор просто принимает ранее перечисленные параметры**

---

### Метод Draw

**Отрисовывает призрака на его координатах**

---

### Метод move_towards_player

**Следует за игроком, принимает на вход только координаты игрока**

---

### Метод collision_with_wall

**Определяет была ли коллизия между призраком и стеной, принимает на вход только координаты призрака в данный момент**
