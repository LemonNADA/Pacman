- [ ] [Create](https://docs.gitlab.com/ee/user/project/repository/web_editor.html#create-a-file) or [upload](https://docs.gitlab.com/ee/user/project/repository/web_editor.html#upload-a-file) files
- [ ] [Add files using the command line](https://docs.gitlab.com/ee/gitlab-basics/add-file.html#add-a-file-using-the-command-line) or push an existing Git repository with the following command:

```
cd existing_repo
git remote add origin https://gitlab.informatics.ru/2024-2025/online/s111/packman_group1.git
git branch -M main
git pull origin main
```

## Репозиторий группы номер 1 (название будет изменено)
```
В рамках этого репозитория вы работаете над своим проектом.
Каждому ученику будет назначена своя задача/ряд задач, которую нужно будет реализовать для сдачи проекта.
Список всех своих задач можно увидеть в окне Plan->Issues
Выполненную задачу необходимо реализовать локально, на ОТДЕЛЬНОЙ ВЕТКЕ. 
Каждую ветку нужно называть как feature/название_задачи_латиницей
После создания ветки запулить её и разработать модуль для решения задачи в ней.
После успешной реализации - отправить ветку в репозиторий.
НЕ СЛИВАТЬ ЕЁ С main!

```
